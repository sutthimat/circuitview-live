# CircuitView Live

A PowerPoint content add-in: a live CircuitView view inside a slide (power-electronic circuit with its conduction
paths at a time cursor on simulated waveforms). Drag the cursor, step through switching edges, zoom, play.
The site holds code only; every slide keeps its own data inside the presentation.

Add it to PowerPoint: Insert > Get Add-ins > My Add-ins > Upload My Add-in, and choose
[manifest.xml](https://sutthimat.github.io/circuitview-live/manifest.xml) (save the file first).
Then Insert > My Add-ins > CircuitView Live on a slide.
